# Package verification

All twelve final note PNGs were decoded and checked against the authoritative filenames and pixel dimensions. Final note exports are flattened RGB. All twelve monetary-artwork derivatives have genuine transparency and non-empty ink content.

A second execution of the delivered builder produced identical pixels for every final note. The optional full-canvas placed-layer export was exercised on EUR100_verso. The package includes the selected scene and artwork pixels, the exact context used for each artwork generation, prompts, fixed assets and working build scripts.

The contact sheet and representative full-size notes were reviewed for palette coherence, hierarchy, legibility, image-to-rail transitions, shared institutional geometry and unintended layer collisions. The orchestral plate used an explicit seating occupancy guide and a targeted instrument revision.

The generated scenes are conceptual architectural illustrations, not engineering drawings. Prototype lettering uses the documented source font; signature, serial, tactile and technical security production remain reserved as the proposal specifies.
