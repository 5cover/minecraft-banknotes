# Crafting Europe — reproducible banknote design package

This package implements proposal version 5 as twelve finished fictional banknote designs: recto and verso for €5, €10, €20, €50, €100, and €200.

The supplied ore cubes, typeface, EU flag SVG, and Europe map SVG remain reusable source assets. Twelve approved scene plates are combined with deterministic typography, denomination-specific badge and ornament plates, institutional fields, and print texture. Final files have no presentation margin or photographed context.

## Build

From this directory, run:

    python3 scripts/build_type_assets.py
    python3 scripts/build_ornament_assets.py
    python3 scripts/build_notes.py
    python3 scripts/build_contact_sheets.py
    python3 scripts/validate_package.py

Dependencies are listed in `requirements.txt`.

## Main outputs

- `outputs/notes/`: twelve flattened PNG banknotes at the exact sizes in `design-package.md`;
- `outputs/contacts/`: recto, verso, and paired series review sheets;
- `generated/scenes/`: twelve swappable scene plates;
- `generated/ornaments/`: twelve denomination-and-side-specific full-canvas ornament plates;
- `generated/badges/`: six empty recto badge plates;
- `assets/type_svg/` and `assets/type_png/`: deterministic type masters and build rasters.

## Editing model

Replace a scene or ore asset, or alter the geometry in `layout.yaml`, then rerun the note and contact-sheet builders. Stable institutional assets and type are not regenerated by the image model.

The series is an independent thematic design study. It is not legal tender and does not reproduce any existing banknote.
