# Approved scene prompt record

All twelve scenes were produced with the built-in image-generation workflow. Each prompt used the shared production rules below, followed by the side-specific subject.

## Shared rules

- clean full-bleed image plate with no banknote frame or lettering;
- wide, elevated, oblique spectator-like composition;
- canonical or near-canonical Minecraft textures, terrain behavior, objects, lighting, and game-scale proportions;
- crisp block surfaces without universal dark outlines;
- mildly saturated color managed like ink on warm banknote paper;
- calmer far-left and far-right areas for later deterministic overlays;
- no UI, crosshair, inventory bar, badge, ore-cube inset, flag, map, numeral, signature, pseudo-text, icon strip, arrow, glossy CGI, cinematic bloom, invented blocks, or generic voxel-fantasy architecture.
